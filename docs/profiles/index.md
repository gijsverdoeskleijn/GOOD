# Documentation profiles

The canonical `developer` profile is the only active output at launch. It
contains the complete internal portal represented by the root navigation.

CalTQ-inspired additional profiles may later assemble selected reusable content
for a release package or public website. A new profile requires an owner,
purpose, audience, access policy, inclusion rules, visible profile identifier,
and acceptance tests. It must not create a second authoritative version of the
Development Plan.
