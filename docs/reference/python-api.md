# Python API reference

The build enables Sphinx `autodoc`, `autosummary`, and NumPy/Google-style
docstrings. Add approved package checkout paths to the source registry and CI
before adding `automodule` directives here.

The generated reference must identify the repository revision used by the
build. It must not import untrusted packages in a privileged environment.
