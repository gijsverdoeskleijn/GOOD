## Component page template

Every new component page must contain:

1. purpose and boundaries;
2. owner and contributors;
3. repositories and documented revisions;
4. provided and consumed interfaces;
5. runtime and deployment context;
6. configuration and provenance responsibilities;
7. tests, operational indicators, and known limitations;
8. lifecycle status and review date.
