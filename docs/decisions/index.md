# Architecture decision records

Use Architecture Decision Records (ADRs) for decisions that affect several
repositories, interfaces, security boundaries, provenance, deployment, or long-
term maintainability.

An ADR records context, decision, alternatives, consequences, owners, date,
status, and links to implementation evidence. ADRs are immutable after
supersession: create a new ADR and link both records.
