# Documentation governance

```{toctree}
:maxdepth: 1

contributing
ai-maintenance
```

GOOD team members own the documentation in their domain. Changes use the same
issue, branch, pull-request, review, and traceability practices as software.
Code remains the primary source for technical behavior; approved PDF material
remains the source for project commitments and controlled background.

The AI documentation agent is the primary maintainer, but not the approving
authority. It reports evidence, prepares changes, creates issues, and drafts
pull requests. Named human owners approve and merge.
